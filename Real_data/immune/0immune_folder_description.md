This folder contains the scripts to reporduce the analysis in the  real data example of the paper of Section 4.2, in particular:

- immune_MCMC_and_results.R contains the code for analyzing the immune dataset 
- immune_data.RDS the dataset
- imputation_workfow.Rmd the code for reproducing the main analysis
- imputaton_workflow.md the output of the main analysis
- imputation_APAFA.R and immune_imputation_TETRIS.R. The code for reproduciong Figures 17-18 of the Supplementary materials
