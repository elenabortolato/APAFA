This folder contains the scripts to reporduce the analysis in the  real data example of the paper of Section 4.2, in particular:

- immune_data.RDS the dataset
- immune.Rmd the code for reproducing the main analysis
- immune.md the output of the main analysis
- imputation_APAFA.R The code for reproducing Figure 20 of the Supplementary materials 
- imputation_TETRIS.R The code for reproducing Figure 21 of the Supplementary materials
