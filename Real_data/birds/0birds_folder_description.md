The file birdsms.Rmd contains the code for performing all tha analyses in the real data example of the paper of Section 4.1.

the folder /data comprises the files:
- data.csv contains count data of bird species observed in 200 locations over time
- traits.csv contain sinformation on the species observed (mass, habitat)
- birds_results.RData contatining the results of the analysis

the folder /birdsms-files contains the figures generated from the markdown.
